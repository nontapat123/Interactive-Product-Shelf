# Interactive-Product-Shelf
ชื่อโปรเจกต์: "Interactive Product Shelf" (ชั้นวางสินค้าอัจฉริยะแบบตอบโต้ได้)
ไอเดียนี้คือการจำลองชั้นวางสินค้าในห้างสรรพลินค้าที่สามารถรับรู้พฤติกรรมลูกค้าและให้ข้อมูลได้อัตโนมัติ
____________________________________________________________________________

1. Live Interaction: จำลองว่าคุณเป็นลูกค้า เดินเข้าไปหาโปรเจกต์ แล้วพอเข้าไปใกล้ ไฟ LED ติดขึ้นมา
เอง (โชว์ HC-SR04)
2. Product Engagement: หยิบกล่องสินค้าจำลองที่ติด MPU6050 ไว้ขึ้นมา แล้วโชว์ว่าบน Dashboard
มีข้อความเดังขึ้นมาว่า "Customer is looking at Product A" (โชว์การสั่นสะเทือน/องศาการเอียง)
3. Out-of-Stock Alert: ลองเอากล่องออกจากช่องวางสินค้าเพื่อให้แสงตกกระทบ LDR แล้วโชว์หน้าจอ
Dashboard flนจังเดือนว่า "Stock Empty! Please refill"
อุปกรณ์ที่ต้องใช้ (BOM List)
ㆍESP32 DevKit V1 (ประมวลผลหลัก)
ㆍ HC-SR04 (นับคน/ตรวจจับความใกล้)
ㆍMPU6050 (ตรวจจับการหยิบสินค้า)
ㆍLDR (เช็คสด็อกสินค้า)
ㆍBuzzer & LED (ตอบสนองกับลูกค้า)
ㆍButton (ฟังก์ขัน Reset หรือเช็คสถานะหน้างาน)
